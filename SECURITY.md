# Güvenlik Politikası

Bu projede güvenlik açıkları ve kritik güvenlik sorunları için erken bildirim önemlidir.

## Bildirim süreci

Güvenlik açığı fark ederseniz, lütfen doğrudan public issue yerine özel iletişim kanalı kullanın; repo sahibi tarafından uygun iletişim bilgisi sağlanmalıdır.

## Bildirimi hazırlarken

Aşağıdaki bilgileri eklemeyi düşünün:

- Etkilenen bileşen veya dosya
- Hata türü
- Hızlı yeniden üretim adımları
- Olası etkilenme alanı
- Önerilen düzeltme veya azaltma planı

## Açıklık ilkesi

Güvenlik bildirimi doğrulandıktan sonra, gerekli işlem için uygun adımlar uygulanır. Açık yayılımın riskini azaltmak adına, güvenlik sorunları gerekli olduğunda gizli tutulabilir.
